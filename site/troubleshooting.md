# 🩹 Не видны слэш-команды `/l1-*`

> Команды `/l1-*` — это обычные файлы в папке твоего ИИ-агента. Если команд нет в меню `/`, значит, агент не нашёл их в той папке, которую читает.

## Шаг 1. Обнови файлы и открой новую сессию

```bash
npx l1dder@latest update
```

После этого начни новую сессию агента или перезапусти его: уже открытая сессия может не увидеть новые команды.

## Шаг 2. Проверь, что файл команды на месте

`npx l1dder doctor` папки агентов не проверяет, поэтому посмотри на сам файл:

| Агент | Какой файл должен быть в проекте |
|-------|----------------------------------|
| **Claude Code** | `.claude/skills/l1-task/SKILL.md` |
| **Cursor** | `.agents/skills/l1-task/SKILL.md` или `.cursor/skills/l1-task/SKILL.md` |
| **OpenAI Codex** (команды вызываются как `$l1-task`) | `.agents/skills/l1-task/SKILL.md` |
| **OpenCode** | `.agents/skills/l1-task/SKILL.md` |
| **Windsurf** | `.windsurf/workflows/l1-task.md` |
| **GitHub Copilot** | `.github/prompts/l1-task.prompt.md` |
| **Cline / Roo Code** | Отдельных команд нет: `L1DDER` устанавливает для них только правила. Напиши в чат: `Выполни l1dder/skills/l1-task/SKILL.md` |

Команда для проверки работает и в терминале macOS/Linux, и в PowerShell:

```bash
ls .claude/skills/l1-task/SKILL.md
```

## Шаг 3. Если файла нет, подключи агента

Скорее всего, агента не выбрали при установке. Перечисли **всех** агентов, которыми пользуешься:

```bash
npx l1dder@latest sync --agents cursor,claude
```

> ⚠️ Папки скиллов агентов, которых нет в списке, будут удалены. Первоисточник `l1dder/skills/` при этом останется на месте.

Затем открой новую сессию агента.

## Если не помогло: частые случаи

### Claude Code вместе с Codex или OpenCode, версия `1.0.1` или старше

В этих версиях скиллы попадали только в `.agents/skills/`, а Claude Code читает только `.claude/skills/`. Обнови `L1DDER` командой из Шага 1: в новых версиях скиллы лежат в обеих папках.

### Cursor не видит команды, а установлен только `claude`

Папку `.claude/skills/` Cursor читает только с включённой настройкой **Third-Party Imports** (`Cursor Settings → Agents`). Надёжнее добавить Cursor в список агентов, как в Шаге 3: тогда команды появятся в папке, которую он читает всегда.

### Коллега склонировал проект, и у него нет команд

Папки агентов не попали в git. Закоммить их или попроси коллегу выполнить `npx l1dder sync` после клонирования.

### Windows

Ничего дополнительно настраивать не нужно: `L1DDER` кладёт команды обычными копиями, поэтому симлинки и режим разработчика не требуются.
