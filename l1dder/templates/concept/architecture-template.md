## 3. Основные потоки данных

```mermaid
sequenceDiagram
    participant U as Пользователь
    participant UI as Вход / UI
    participant Core as Ядро
    participant DB as Хранилище

    U->>UI: Действие / Запрос
    UI->>Core: Вызов публичного интерфейса
    Core->>DB: Чтение / Запись
    DB-->>Core: Данные
    Core-->>UI: Результат
```
