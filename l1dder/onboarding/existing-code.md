# Onboarding: Existing Code (L1DDER)

> **Самый быстрый способ:** просто введи в чате агента команду **`/l1-onboard`** (или отправь промпт ниже).

---

## Промпт для агента (если запускаешь без слэш-команды)

```
У нас есть рабочий проект с кодом, но без документации по методологии L1DDER.
Нужно провести реверс-инжиниринг: извлечь знания из кода, по этапам восстановить долгосрочный концепт, затем описать стек (30-tech-stack.mdc) и инициализировать Банк Идей, Бэклог и Роадмап.

Методология находится в l1dder/. Прочитай l1dder/METHODOLOGY.md и l1dder/skills/l1-onboard/SKILL.md прежде чем начинать.

Работай по этапам в режиме existing-code (read-only для кода приложения). Первоисточник фактов — код, а существующие CLAUDE.md, AGENTS.md и .cursor/rules/ — только вспомогательный источник:
1. Иди по шести этапам, по одному файлу за раз: идея → видение → архитектура → модель данных → стек (выпиши его из конфигов проекта, а не выбирай заново) → docs/ideas.md, docs/backlog.md, docs/roadmap.md и docs/README.md.
2. На каждом этапе сначала составь черновик по коду и спрашивай только о том, чего в коде нет: до 7 вопросов с рекомендациями, затем «Идём дальше или ещё раунд?».
3. Файл этапа записывай только после моего явного «ок».
```
