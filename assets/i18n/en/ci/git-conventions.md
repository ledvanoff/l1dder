# Git Conventions (L1DDER)

## Branches
```
<type>/<scope>-TASK-NN.MM-<short-description>
```
Types: `feat`, `fix`, `chore`, `docs`, `refactor`.

## Commit Messages
```
<type>(<scope>): <imperative description>
```

## Pull Requests
- Base branch: `main`.
- Merge strategy: **Squash and Merge**.
- Include the full ID Passport (`IDEA-NNN → FEAT-NNN → SPRINT-NN → TASK-NN.MM`) and links to `plan.md` and `summary.md`.
