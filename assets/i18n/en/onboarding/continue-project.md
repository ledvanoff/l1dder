# Onboarding: Continue Project (L1DDER)

> **Mode:** Project already initialized on **L1DDER**.

| Situation | Command |
|-----------|---------|
| Capture & refine a new idea (`docs/ideas.md`) | `/l1-idea [idea]` |
| Write a feature spec (`docs/specs/`) & slice into Backlog (`docs/backlog.md`) | `/l1-feature [IDEA-NNN]` |
| Schedule or reorder the Roadmap (`docs/roadmap.md`), or reject the current sprint with rollback | `/l1-planning` |
| Execute the next task from the Roadmap (or run final `Doctor Checklist`) | `/l1-task` |
| Fix an urgent bug bypassing the Roadmap | `/l1-hotfix [bug]` |
| Change the project itself, not the product: git rules, CI, libraries, `Makefile`, agent rules | `/l1-chore [what to change]` |
| Quickly build a small product feature when no sprint is active (strictly human-invoked, forbidden for the agent on its own) | `/l1-fast [small feature]` |
