# Контракты API и модулей

> Межмодульные или HTTP/RPC контракты системы.

---

## 1. Общие конвенции

- **Формат данных:** JSON (UTF-8) / типизированные структуры.
- **Валидация:** строгая проверка входных параметров на границе доверия.
- **Формат ошибок:** понятный код ошибки и человекочитаемое сообщение.

---

## 2. Сводная таблица эндпоинтов / методов

| Метод / Вызов | Путь / Сигнатура | Успешный ответ | Сценарий |
|---------------|------------------|----------------|----------|
| `POST` | `/api/v1/[resource]` | `201 Created` | `[Создание ресурса]` |
| `GET` | `/api/v1/[resource]` | `200 OK` | `[Получение списка]` |
| `GET` | `/health` | `200 OK` | Проверка работоспособности |
