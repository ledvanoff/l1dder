# L1DDER — Spec-Driven & Roadmap-Gated AI Development Framework

---

## Суть продукта

**L1DDER** — это самодостаточный методологический фреймворк и мульти-агентный CLI-установщик (`npx l1dder`) для итеративной Spec-driven разработки с ИИ-агентами (**Cursor, Claude Code, OpenAI Codex, Windsurf, GitHub Copilot, OpenCode, Cline**).
Он отказывается от хрупких скрытых стейт-машин (`state.yml`) и блокирующих git-хуков в пользу архитектуры **Zero Hidden State**: единственным источником истины выступают Markdown-документы в `docs/` со сквозными паспортами ID (`ID Passport`).

---

## Для кого

- **Вайбкодеры и Product Owner'ы** — управляют разработкой продукта на понятном языке через 6 слэш-команд (`/l1-onboard`, `/l1-idea`, `/l1-feature`, `/l1-planning`, `/l1-task`, `/l1-hotfix`) и подтверждение словом **«ок»** на точках остановки (`⛔ СТОП`).
- **Инженеры и команды разработки** — получают единый стандарт спецификаций (`FEAT-NNN`), декомпозиции (`SPRINT-NN`, `TASK-NN.MM`), встроенные инженерные дисциплины (`ponytail` + `mattpocock/skills`) и обязательную ревизию качества спринта (`TASK-NN.99` `Doctor Checklist`).

---

## Какую задачу решает

Без `L1DDER` разработка с ИИ-агентами быстро скатывается в хаос: агент начинает писать код без согласованного плана, плодит оверинжиниринг, забывает контекст на третий день, а документация расходится с кодом. С другой стороны, попытки зажать агента через внешнюю стейт-машину (`state.yml` и git-хуки) приводят к постоянным рассинхронизациям и блокировкам.
`L1DDER` даёт предсказуемые рельсы процесса для любой (даже быстрой и дешёвой) модели ИИ за счёт линейных пошаговых скиллов, матрёшки сквозных ID и финального `Doctor Checklist` в конце каждого спринта.

---

## Что в первой очереди (MVP `v1.0.0`)

- Ультра-тонкий CLI (`npx l1dder init`, `update`, `sync`, `skills`, `changelog`, `doctor`) без внешних runtime-зависимостей.
- Полная двуязычная поставка (`--lang ru` и `--lang en`) правил, шаблонов и путеводителя.
- 20 встроенных скиллов в коробке (`7 /l1-*` + `4 ponytail*` + `9 mattpocock/skills`) и манифест `l1dder/skills.json` для стек-скиллов.
- Генерация нативных правил и команд для `Cursor`, `Claude Code`, `Codex`, `Windsurf`, `Copilot`, `OpenCode`, `Cline`.
- Предупреждение о `BREAKING CHANGES` с интерактивным подтверждением перед обновлением (`npx l1dder@latest update`).
- Двуязычный сайт документации на VitePress + Mermaid для GitHub Pages.
