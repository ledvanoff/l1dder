## 1. Контекст и связь с идеей `IDEA-002`

Фича `FEAT-002` реализует `IDEA-002`: проверяет на практике, как две разные быстрые модели (`Composer` и `Grok`) справляются с правилами и скиллами `L1DDER` в изолированном полигоне `playground/`, вычищает кодовую базу и шаблоны через `ponytail` и все встроенные скиллы, и доводит пакет `l1dder@1.0.0` до выкатки в GitHub и npm.

---

## 2. User Stories и Acceptance Criteria

### US-1: Подготовка полигона `playground/` и автоматический тест на 2 моделях (`Composer` и `Grok`)

**As a** автор фреймворка `L1DDER`
**I want** автоматически подготовить чистые песочницы в `playground/` и прогнать сквозной сценарий методологии на двух независимых моделях (`Composer` и `Grok`) с автоматической проверкой результата скриптом `playground/verify.mjs`
**So that** я на 100% уверен, что инструкции `L1DDER` понятны разным моделям и не дают сбоев в цепочке ID.

**Acceptance Criteria:**
```
GIVEN собранный CLI (dist/cli.js) и скрипт подготовки полигона (playground/prepare.mjs)
WHEN  запускаются изолированные песочницы для Composer и Grok и модели выполняют цепочку L1DDER (/l1-idea -> /l1-feature -> /l1-planning -> /l1-task)
THEN  автоматический скрипт проверки playground/verify.mjs подтверждает 0 ошибок по всем чекам (наличие файлов, точность ID Passport IDEA-001 -> FEAT-001 -> SPRINT-01 -> TASK-01.01 и TASK-01.99, корректность статусов и выполненный код) для обеих моделей
```

### US-2: Полный аудит через `ponytail` и инженерные скиллы с исправлением косяков

**As a** автор фреймворка `L1DDER`
**I want** прогнать код CLI (`src/`, `tests/`, `scripts/`) и шаблоны/скиллы (`assets/i18n/{ru,en}/`) через `ponytail-audit`, `ponytail-review`, `ponytail-debt`, `codebase-design` и двухосевой `code-review`
**So that** в релизе `1.0.0` не осталось мёртвого кода, дублирования, битых ссылок или расхождений между `ru` и `en`.

**Acceptance Criteria:**
```
GIVEN результаты прогона на моделях Composer/Grok и кодовая база L1DDER
WHEN  проводится аудит по ponytail-audit, ponytail-review, ponytail-debt и code-review
THEN  все найденные замечания в коде и промптах скиллов устранены, а make ci проходит с 0 ошибок
```

### US-3: Выкатка версии `1.0.0`

**As a** автор фреймворка `L1DDER`
**I want** подготовить финальный релизный пакет `l1dder@1.0.0` (`npm pack --dry-run`, `CHANGELOG.md`, `assets/releases.json`, git-репозиторий и пуш в GitHub / npm)
**So that** коллеги могут сразу установить `npx l1dder init` и открыть сайт документации на GitHub Pages.

**Acceptance Criteria:**
```
GIVEN пройденные автотесты CLI, зелёный вердикт playground/verify.mjs на 2 моделях и собранный сайт документации
WHEN  выполняется подготовка и выкатка релиза v1.0.0
THEN  пакет готов и проверен через npm pack --dry-run, git-репозиторий синхронизирован и готов к пушу тега v1.0.0
```
