## 1. Что реализовано

- `scripts/check-site.mjs` — проверка готовой сборки без новых зависимостей: ссылки, якоря, файлы и базовый путь, сравнение со снимком и запись снимка.
- `tests/check-site.test.ts` — 18 тестов на маленьких примерах сборки.
- `Makefile` — проверка в `make test-e2e`, новая цель `make site-gate`.
- `docs/sprints/SPRINT-02-seo-foundation/site-baseline.json` — снимок 18 страниц до SEO-правок, совпадает с живым сайтом.
- `site/index.md`, `site/en/index.md` — исправлены две битые ссылки на раздел манифеста (не хватало `_` в якоре).
- `l1dder/rules/30-tech-stack.mdc` и `docs/specs/FEAT-003-seo-foundation/{design,tasks}.md` — описаны новый скрипт и цель `make site-gate`.

---

## 2. Отклонения от плана

- Первая версия (`87fe9a8`) написала все 18 тестов сразу: каждый падал только потому, что скрипта ещё не было. По просьбе пользователя скрипт и тесты пересобраны с нуля по одному тесту (`675c273`), теперь каждый тест падал на своём поведении. Исключение — защитный тест «ничего не ухудшилось»: он зелёный сразу, его способность падать подтверждена временной мутацией правила.
- Снимок, записанный новым скриптом, побайтно совпал с прежним.
- Правки закоммичены и запушены в `dev` до второго «ок», потому что CI на Windows входил в DoD плана. Первый коммит также содержит документы спринта. Этот `summary.md` и обновлённые статусы закоммичены отдельно, после «ок».

## 3. Принятые решения (и влияние на долгосрочную документацию)

| Решение | Причина | Отражено ли в `concept/` / `specs/` / `ADR-NNNN` |
|---------|---------|--------------------------------------------------|
| Сравнение со снимком вынесено в `make site-gate`, а `make ci` проверяет только ссылки, якоря и файлы | Постоянное сравнение мешало бы будущим правкам документации, например сокращению текста | [`design.md`](../../../../specs/FEAT-003-seo-foundation/design.md), `l1dder/rules/30-tech-stack.mdc` |
| Текст считается по всему `<body>`, а не по `<main>` | У главной в `<main>` только первый экран, блоки с возможностями лежат вне него | Поведение покрыто снимком |
| Разбор HTML регулярными выражениями без зависимостей | Разметка VitePress предсказуема, страница без H1 роняет проверку | [`plan.md`](./plan.md) |

## 4. Проблемы и решения

| Проблема | Как решили |
|----------|-----------|
| Проверка нашла две битые ссылки на живом сайте: с главных страниц на раздел манифеста в `agents-cli` | Добавлен `_` в начало якоря. На живой сайт исправление попадёт с релизом |
| В первой версии тест потерянной ссылки меню падал на уменьшении текста: ссылка на `guide` оставалась в боковой панели | В примере убрана ссылка на главную, которой нет в панели |
| Тесты первой версии не доказывали, что каждый ловит своё поведение | Скрипт и тесты пересобраны по одному тесту |
