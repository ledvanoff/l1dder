## 1. Что реализовано

- `scripts/release.mjs`, `Makefile` — `make release` останавливается, если сайт хуже снимка (`make site-gate`).
- `scripts/check-site.mjs`, `tests/` — усилена проверка: точные `hreflang`, повторы в `sitemap.xml`, описания в `llms.txt`, повреждённый снимок, флаг без значения, сообщения с именем страницы.
- `l1dder/rules/30-tech-stack.mdc`, `AGENTS.md` — обязательные правила про таблицу `seo.mts` и заголовки в выдаче, цели `make site-gate` и `make site-baseline`, сведения о корневом сайте.
- `docs/concept/architecture.md`, `docs/specs/FEAT-003-seo-foundation/` — приведены в соответствие с кодом.
- Репозиторий `ledvanoff/ledvanoff.github.io` — личная страница, теги Google и Яндекса, `robots.txt`, `llms.txt`. Оба поисковика подтвердили права.

**Результаты проверок на production-сборке:** `make ci` и `make site-gate` без ошибок, 93 теста. В браузере 18 из 18 страниц на ширине 1280 и 375, 18 диаграмм, 18 уникальных заголовков, навигация, смена языка, поиск RU и EN, две темы, ошибок консоли нет.

## 2. Отклонения от плана

- **Блок 5 (релиз) не выполнялся.** Решение пользователя: версия `1.0.3` не выпускается, потому что в самом продукте почти ничего не изменилось, изменения поедут со следующим продуктовым релизом. Закрытие Блока 6 поэтому прошло без релиза. Затем по отдельному разрешению пользователя `dev` влит в `main` без тега (`5207863`): обновились сайт и README на GitHub, npm не менялся.
- Отложенные проверки вынесены в [`docs/backlog.md`](../../../../backlog.md#feat-003).
- Гейт повторён на живом сайте: 18 из 18 страниц на ширине 1280 и 375 (теги, 18 диаграмм, нет прокрутки), поиск RU 16 и EN 14 результатов, язык, тема, меню на телефоне, прокрутка к якорю, ошибок консоли нет.
- Личная страница несколько раз переделывалась по замечаниям пользователя. Это отдельный репозиторий, на проверки спринта это не влияет.

## 3. Принятые решения (и влияние на долгосрочную документацию)

| Решение | Причина | Отражено ли в `concept/` / `specs/` / `ADR-NNNN` |
|---------|---------|--------------------------------------------------|
| Закрыть спринт без релиза и выкатить только сайт | Решение пользователя: npm ждёт продуктовых изменений, поисковая выдача не ждёт. Pages разрешает деплой только из `main`, поэтому `dev` влит туда без тега | `tasks.md`, `backlog.md`, `roadmap.md` |
| `make release` сам запускает `make site-gate` | Требование «не сломать сайт» иначе зависело от памяти агента | `30-tech-stack.mdc`, `requirements.md` |
| Снимок обновляется только через `make site-baseline` с причиной в коммите | Снимок устаревает при намеренных правках | `30-tech-stack.mdc` |
| Теги подтверждения живут на корневом сайте | Яндекс подтверждает весь адрес, а не путь `/l1dder/` | `tasks.md`, `30-tech-stack.mdc` |
| ADR не нужен | Значимых архитектурных решений не было | — |
