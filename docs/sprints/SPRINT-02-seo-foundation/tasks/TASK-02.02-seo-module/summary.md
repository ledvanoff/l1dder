## 2. Отклонения от плана

- Заголовок и описание главной изменены по просьбе пользователя ещё до реализации: заголовок не называет отдельных агентов, описание перечисляет все семь.
- Два раза один шаг охватил два теста, падавших вместе: нет `sitemap.xml` и нет страницы в нём, неверный и отсутствующий канонический адрес.
- Защитные тесты уникальности и длины текстов были зелёными сразу, потому что таблица уже была верной. Их способность падать проверена временными мутациями: повторный заголовок и слишком длинный.
- Тест повторного описания не имел отдельного падения на своём поведении: правило появилось вместе с проверкой пустого описания.
- `l1dder/rules/30-tech-stack.mdc` изменён вне Scope плана ради точности описания.
- В коммит `af7c456` вошли документы закрытия `TASK-02.01`.

## 3. Принятые решения (и влияние на долгосрочную документацию)

| Решение | Причина | Отражено ли в `concept/` / `specs/` / `ADR-NNNN` |
|---------|---------|--------------------------------------------------|
| `x-default` ведёт на английскую версию | Для читателей, не знающих ни русского, ни английского, английский понятнее | [`plan.md`](./plan.md) |
| Без `lastmod` в `sitemap.xml` | `lastUpdated` добавляет на страницы новую строку | [`plan.md`](./plan.md) |
| Обязательная запись в правила про таблицу `seo.mts` и заголовки в выдаче | Требование пользователя | [`tasks.md`](../../../../specs/FEAT-003-seo-foundation/tasks.md), критерий 10 спринта, выполняется в `TASK-02.99` |

## 4. Проблемы и решения

| Проблема | Как решили |
|----------|-----------|
| Тесты повторных заголовка и описания ожидали сообщение с другим порядком страниц, а прогон срезов пошёл дальше без остановки | Причина найдена в журнале: страницы проверяются по алфавиту. Исправлены ожидания, реализация была верной |
| Скриншот панели браузера и прокрутка отставали, потому что панель скрыта | Состояние перепроверено с задержкой: прокрутка к разделу и окно поиска работают |
