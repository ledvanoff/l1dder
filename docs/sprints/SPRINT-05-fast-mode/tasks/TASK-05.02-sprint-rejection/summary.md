## 2. Отклонения от плана

- **Git как журнал `/l1-fast`.** Добавлено на `⛔ СТОП №1` по вопросу пользователя о микрологе. Раньше `/l1-fast` ничего не коммитил до конца, и прерванный быстрый спринт нельзя было отделить от правок соседней вкладки. Теперь бронь и задачи коммитятся по ходу работы, и отклонение одинаково для обычного и быстрого спринта. Особый случай «бронь без документов» в О4 свёлся к одной фразе: агент обновляет только существующие документы.
- **Возврат документов в О3.** Сначала было `git checkout HEAD -- docs/`. Ревью нашло, что эта команда затёрла бы незакоммиченную спеку из соседней вкладки. Теперь возвращаются только пути из отката: `git diff --cached --name-only -- docs/ | xargs git checkout HEAD --`.
- **Страж RU/EN сужен до ветки отклонения.** Верхняя часть EN `/l1-planning` и до этой задачи была короче RU. По решению пользователя синхронизация и расширение стража **обязательно** переносятся в `TASK-05.03`; это записано в бэклоге, README спринта, `tasks.md` и `requirements.md`.

## 4. Проблемы и решения

| Проблема | Как решили |
|----------|-----------|
| Heredoc с кириллицей в `python3 -` упал на кодировке | Скрипты правок пишутся в файл в scratchpad и запускаются оттуда |
| Страж RU/EN на весь `/l1-planning` упал на старом расхождении EN | Страж ограничен веткой отклонения, синхронизация записана обязательной частью `TASK-05.03` |
| `git checkout HEAD -- docs/` мог затереть чужие незакоммиченные документы | Возврат только путей из отката; проверено на живом временном репозитории |
| В EN-шаблоне раздел истории называется `Roadmap Changelog`, а не `Change History` | Тест и текст ветки приведены к фактическому заголовку |
