## 1. Цель спринта

Пользователь любого проекта на `L1DDER` делает небольшую фичу продукта через `/l1-fast`: сначала код, потом честные реестры, с двумя остановками и без ослабления проверок; при активном спринте получает строгий отказ и может отклонить текущий спринт с откатом через `/l1-planning` (`FEAT-006` ← `IDEA-005`).

---
